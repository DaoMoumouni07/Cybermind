# 🛡️ CyberMind — AI Cybersecurity Platform

## Description
CyberMind est une plateforme intelligente de détection de cybermenaces 
combinant Machine Learning, IA générative et Big Data.

## Fonctionnalités
- 🦠 Analyse de malware par Random Forest
- 🔍 Assistant Pentest avec recherche CVE (RAG)
- 🤖 Explications générées par LLaMA 3.3 via Groq
- 📊 Dashboard Big Data temps réel

## Stack technique
- Python 3.11 | Streamlit | Scikit-learn
- ChromaDB | LLaMA 3.3 (Groq) | Kafka | Elasticsearch

## Lancement
pip install -r requirements.txt
streamlit run app.py
